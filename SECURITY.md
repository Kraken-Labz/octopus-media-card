# Security policy

Do not include credentials, cookies, signed URLs, real service addresses, user IDs, diagnostic exports, or private fixtures in a report.

Report vulnerabilities privately through the repository's [GitHub security advisory page](https://github.com/phgsbr/octopus-media-card/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Security-sensitive design requirements are documented in `docs/architecture.md`.
