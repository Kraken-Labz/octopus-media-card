# Contributing

The project is in scaffold development. Open an issue before expanding scope or adding a new external service.

## Requirements

- Python 3.14.2 or newer for the Home Assistant 2026.7.x test environment;
- Node.js 22 or newer;
- pnpm 11;
- no access to a real media server during automated tests.

## Before submitting a change

Run backend lint, types, and tests; run frontend lint, tests, build, and bundle verification. Confirm that fixtures are fictional and that the diff is limited to this repository.

Generated bundles must never be edited manually.
