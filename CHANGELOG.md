# Changelog

## 0.1.0

First public release preparation. This version includes:

- Jellyfin Recent and Playing data.
- Radarr and Sonarr Upcoming data.
- Visual configuration editor with real previews.
- Auto, dark, and light appearance modes.
- Recent and Upcoming auto-scroll with interaction and reduced-motion handling.
- English and Brazilian Portuguese localization.
- Octopus Media branding assets.
- ConfigEntry reconfigure support that preserves entry identity.
- Explicit recovery UX for cards referencing removed ConfigEntries.
- Secure, opaque image references and authenticated image delivery.

This changelog entry prepares version 0.1.0; no GitHub release or tag has been created yet.
